# a50 验收记录

状态：完成。日期：2026-11-26。关联需求：F6.6–F6.7；设计 §13。

改动文件：`src/web/src/llm/citations.ts`、`ChatSession.ts`、`ui/chat/LiveChatPanel.tsx`、`documents/DocumentReader.tsx`、`PageView.tsx`；测试 llm.test 和桌面 LlmAcceptance。

运行命令：`pnpm test:web`、`pnpm test:browser`、`pnpm verify:llm`。

样本与预期：正确 token／唯一引文、重复引文、伪造和跨文档 token、文字 revision 变化、删除关联标注／会话、离屏页。引用只有经过校验才显示精确高亮，导航不得把旧 offset 套到新文字。

实际：受限 `[[p页|引文]]` 与附 token 语法只解析合法页码和有限长度。单元覆盖重复、跨文档、过期、引文篡改；补测即便引文唯一，已拒绝的 token 也不能在点击时退回普通搜索，负 offset 和旧 revision 均无精确范围。桌面正确引用跳到真实原文并闪烁，伪造引文提示未确认且高亮数为零；标注→来源消息→标注可互跳，撤销后消息提示标注已删除。会话删除保留标注，缺失来源提示可读；来源查找可按页加载历史。离屏导航复用已通过的阅读器跳页与跨页组能力。

平台和未覆盖：见 [phase5](phase5.md)。OCR 字框本身仍沿用第四阶段 approximate 精度，引用校验不把近似几何提升为人工真值。
