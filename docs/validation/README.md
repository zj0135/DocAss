# 验证记录

正式任务的验收报告按 `a1.md` 至 `a62.md` 存放，包含关联需求、改动文件、运行命令、样本、预期/实际、平台版本及未覆盖项。只有正式工程达到目标才能勾选任务。

第一阶段的正式实现与验证见 [phase1.md](phase1.md)。A1–A15 已完成实现和本机自动化验收，逐项保留受控场景与后续整机复验的边界。测试源码随仓库保存；原始报告、截图和本机验证数据位于 Git 忽略的根目录 `artifacts/`。

当前 `verify-plan.mjs` 仅检查设计与计划自身的一致性。从仓库根目录执行 `node docs/validation/verify-plan.mjs`，结果写入 `planning-audit.json`。检查范围包括连续任务编号、每项必需字段、依赖存在且指向前置任务、原需求编号全部覆盖、任务引用合法，以及文档相对文件链接可访问。

该检查不证明任务已经实现，不证明验收阈值已经达到，也不检查 Markdown 锚点在所有渲染器中的表现。历史 `../spikes/` 排除在源码仓库外；正式产品门禁见 `../design-v1.md` §16。
