# a51 安全边界验收

状态：完成实现与本机自动化验收。日期：2026-11-26。对应 N1–N3、F6.4/F6.8/F6.11，设计 §4/§12。

改动：SafeMarkdown、PiTransport、MainWindow 外链处理，以及 IntegrationBoundaryTests、LlmTests 和 integration-boundaries/browser integration 测试。

实测恶意 `<script>`、HTML、远程图片与 javascript 链接只显示文本，不执行、不发出外部图像请求；PDF JavaScript 继续禁用。发布 CSP 拒绝框架、对象和任意远端连接；桥调用受应用源、会话能力、docId 和 schema 约束。编码/二次编码穿越、反斜杠、NTFS 路径、任意 SQL、未知文档和跨文档附件被拒绝。

命令：`pnpm test:host`、`pnpm test:web`、`pnpm test:browser`、`node scripts/verify-desktop.mjs --case=channel --skip-build`。原始证据与平台见 [phase6](phase6.md)。当前没有记录正文/密钥的业务日志；轮转日志与发布资源清单仍属 A59。安全 Markdown 是有限语法子集，不宣称完整 CommonMark。
