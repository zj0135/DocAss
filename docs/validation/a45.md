样本与预期：300 页元信息但只有一页就绪，含“忽略规则”文档文字；小窗口、大工具结果、图片和多轮工具历史。摘要不得先 OCR 全文，超预算必须裁剪或提示，文档不得成为 system 指令，不能留下孤立工具结果。

实际：300 页样本输出 readyPageSummaries 和 1/300 coverage；全文仅在全部已就绪且低于 40% 阈值时内联，摘要最多五页各 500 字。UTF-8 字节保守计数，系统工具声明也在 pi 上下文中计入；预留 maxOutputTokens 与 10%，每图额外 8192。超长工具结果替换为明确截短说明；按完整用户回合删除历史，图片或当前问题仍过大则报错。文档进入标记为非可信的 user 数据块。选区从已保存用户消息捕获，不随标签变化。

平台和未覆盖：见 [phase5](phase5.md)。估算刻意保守，不是每个云模型的精确 tokenizer；当前采用裁剪和就绪页摘要，未引入付费摘要调用。
