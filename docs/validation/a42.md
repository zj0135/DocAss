状态：完成。日期：2026-11-26。关联需求：F6.1、F6.3、F6.9、N1、N2；设计 §5.4。

改动文件：`src/host/DocAss.Host/Http/ProviderProxy.cs`、`LoopbackServer.cs`、`Contracts/Protocol.cs`、`MainWindow.cs`；`src/web/src/services/DesktopServices.ts`。

运行命令：`pnpm test:host`、`pnpm verify:llm`。样本：四类本机 HTTP 上游、伪客户端 Authorization／x-api-key／cookie、302／401／429、非法路径、无活动 run、图像请求、取消及 idle／total deadline。

预期与实际：Completions／Responses 注入 Bearer，Anthropic 注入 x-api-key，Gemini 注入 x-goog-api-key；所有四类合成上游确认本机口令和 cookie 未透传。URL 只接受固定协议路径，绝对后缀、父目录及附加凭据 query 被拒绝。302 不跟随，错误分别为 AUTH_FAILED、RATE_LIMITED、UPSTREAM_REDIRECT_BLOCKED。流分块转发并 flush，客户端停止使上游断连接；宿主两个并发和排队取消、idle／total timeout 回归通过。正式 WebView2 的请求体转换为 ArrayBuffer，兼容本机 HTTP/1。

平台和未覆盖：见 [phase5](phase5.md)。HTTPS 使用宿主标准证书验证；HTTP 仅允许本机例外。四协议使用假密钥，真实服务的额外兼容头未作通用承诺。
