# a53 独立浏览器验收

状态：完成。日期：2026-11-26。对应 N8，设计 §15。

改动：BrowserServices IndexedDB schema 3 附件，BrowserFixtures 显式开发入口，以及 integration.spec。运行 `pnpm dev` 无需 .NET；PDF/图片真实 Canvas 渲染，文件、标注、会话和附件持久化。`?fixture=1` 的报告/合同样本提供固定几何、合成 OCR、合成 SSE；经过正式 Reader、pi 和存储路径，底部明确标识合成数据。

验收：真实 PDF 选字、高亮、Ctrl+Enter 生成、刷新恢复、OCR、错误/取消和菜单交互通过；普通非样本文件准确提示桌面服务需求。附件校验归属、签名、尺寸、解码和 SHA-256，刷新可恢复，损坏后不可用但消息保留。默认工作区为空，不自动出现演示文档、不自动生成；开发样本须主动点击，完整原型须显式 `?demo=1`。

命令：`pnpm test:web`、`pnpm test:browser`、`pnpm build`。生产构建通过；BrowserFixtures 用 DEV 条件动态载入，客户端不包含真实 Key，不把示例 API 当真实提供方。浏览器精确文字/OCR/模型仅对固定样本可用，任意文档需要桌面版，属于明确能力边界。证据见 [phase6](phase6.md)。
