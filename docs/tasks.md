# DocAss v1 剩余完整工作任务

基线：2026-11-25；以 [design-v1.md](design-v1.md) 为实施依据。任务编号为 a1–a62，编号连续；没有把原型或 Spike 冒充正式任务完成。

## 使用方式

- 所有任务初始状态为 `[ ]`；完成后改 `[x]`，并填写 `docs/validation/aN.md`。
- 每项记录：关联需求、改动文件、运行命令、样本、预期/实际、平台版本、未覆盖项。截图用于界面验收，结构化结果用于语义/性能验收。
- 依赖列是前置门禁。编号便于顺序执行；涉及多条路径时可以按依赖推进，但不跳过验收。下文“通过”均指正式工程，不能只引用隔离 Spike。
- 原型可复用范围：TitleBar/Toolbar/ToolRail/StatusBar/Splitter、三个侧面板、浮层、聊天和设置外观。真实文件、Canvas 文档、文本几何、OCR、持久化、宿主窗口和真实 LLM 尚未完成。
- 本清单包含接口、正常流程、异常/恢复、安全、性能、部署和文档；不是只列 UI 功能。

## a1–a15：工程、宿主与数据基础

本阶段勾选对应实现与本机自动化验收；显示器移除、用户身份隔离的受控场景及其整机复验边界见 [阶段记录](validation/phase1.md)，不将模拟记作物理操作。

### a1 [x] 固定工程入口与依赖

**依赖**：无。**对应**：设计 §1、§4、§17；N8/N9。

**工作/交付**：创建正式 `DocAss.sln`、`src/host/DocAss.Host` 和测试项目；固定 SDK、平台、前端与宿主依赖/锁文件；根 pnpm workspace 为唯一安装入口，消除 `src/web/pnpm-lock.yaml` 与根锁文件的双重歧义；补 dev/build/test/publish 命令和生产资源复制规则。保留现有 UI 源码。

**验收**：干净依赖目录从锁文件可重复 restore/install；`pnpm build`、宿主 Release build 成功；产物含前端入口和指定版本依赖；生产工程没有 import docs/spikes；文档列清各命令输出位置和运行要求。

### a2 [x] 定义共享契约、错误码与 schema

**依赖**：a1。**对应**：设计 §5–§7、§9–§12。

**工作/交付**：创建 TS/C# 对齐的 DocHandle、PageInfo、PageText、Annotation、Message、Provider、Job、CommitCommand 与响应 schema；固定 1-based 页码、UTF-16 半开范围、UUID/随机能力、revision、operationId/payloadHash；实现运行时校验和错误码字典。

**验收**：同一组合法/非法 JSON fixture 同时运行 TS 和 C#，接受/拒绝结果一致；未知版本、错字段、NaN/无限坐标、越界页号、超长字符串、路径型 ID 明确失败；协议样例能被两端 roundtrip。

契约验收同时包含 Box/Quad 顶点规则、仿射数组方向，以及 contentRevision/documentRevision/textRevision/pageGeneration 的独立失效样例，禁止统一成含义不明的 revision。

### a3 [x] 建立可复现样本和验收框架

**验收**：样本生成可重复，hash/内容可追溯；包含五类原生文本、UserUnit、连字/组合字/emoji、RTL/竖排、密码、扫描/混合、无文字、坏文件；几何总计≥1000非空白glyph有真值，OCR至少100字有人工quad；至少一个测试能捕获旧测宽反例与重定向漏头反例。不得用待测库自身输出生成真值。

### a10 [x] 实现版本确认与幂等提交

**依赖**：a5、a9。**对应**：设计 §9.1；F4.5/N4。

**工作/交付**：CommitCommand事务、expectedRevision CAS、operationId/payloadHash去重、getOperation、单文档写队列、错误后的安全重试；实现标注/消息/工具效果的原子命令基础。

**验收**：同操作重试100次只一个副作用；同ID不同payload拒绝；旧revision不覆盖新数据；故意在各事务步骤抛错无部分行；commit成功但响应丢失后重试得到原结果；100次ack后随机强杀恢复无丢失。

额外覆盖重开文档导致 docId 改变后仍可安全重试；篡改业务内容但保留旧 payloadHash 必须被宿主拒绝；消息 checkpoint 与标注并发提交不互相覆盖。

### a11 [x] 实现跨进程文档写锁与只读模式
