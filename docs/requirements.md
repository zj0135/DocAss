## 1. 目标

DocAss 是一个 Windows 桌面文档助手。用户打开文档后可以阅读、在页面上做标记，并让 LLM 辅助分析和解读文档内容。

## 2. 范围

### 2.1 v1 包含

| 领域 | 内容 |
|---|---|
| 文档格式 | 文字型 PDF、扫描件 PDF、图片（PNG、JPEG 等） |
| 显示 | PDF.js 把页面绘制到 Canvas；滚动、缩放、旋转 |
| 文字交互 | 选择、复制、文档内查找，全部在自研 Canvas 叠加层实现 |
| 标注 | 高亮、下划线、便签、文字批注、手绘、矩形、箭头 |
| OCR | 扫描件和图片由宿主内的 SimdPaddleOCR 识别，识别结果可选择、复制、查找、标注 |
| LLM | 针对当前文档的对话；框选区域提问；回答中的引用可跳转回原文 |
| 工作区 | 多标签页，每个文档有独立的标注和对话 |
| 界面 | 无边框主窗口：标题栏内标签页、工具栏、文档区与侧面板、右侧对话面板、状态栏；浅色主题 |

### 2.2 v1 不包含

- Word 文档。v2 支持，路线是先转成 PDF 再复用同一流程。
- 把标注写回 PDF 文件。v1 只存独立 JSON，v2 提供“导出带标注的 PDF”。
- 跨文档问答和向量检索。
- 分栏和表格的版面分析。
- 单实例运行和文件关联。
- 标注的导入导出（如 XFDF）。
- 深色主题。v1 只有浅色主题，颜色变量预留。
- 标签页拖出为独立窗口。

## 3. 技术约束

- 客户端外壳：WPF + WebView2，宿主尽量薄。
- 前端：React + TypeScript + Vite，业务逻辑尽量放在前端。
- 宿主只承担前端做不了或不该做的事：文件访问、OCR、API Key 保管和 LLM 请求代理、本地存储。
- LLM 层使用开源的 pi（`pi-ai` 和 `pi-agent-core`，MIT 许可）。
- 原始文档永不被修改。

## 4. 功能需求

### 4.1 文档打开与标签页

- F1.1 通过文件对话框或拖放打开 PDF 和图片。
- F1.2 多个文档以标签页形式同时打开，可切换、关闭。
- F1.3 同一文件（内容哈希相同）重复打开时，聚焦已有标签页。
- F1.4 记住每个文档上次的页码、缩放和旋转。
- F1.5 加密 PDF 打开时提示输入密码。
- F1.6 最近打开列表。
- F1.7 无边框窗口：标题栏由应用绘制，标签页位于标题栏内，右侧有新建标签“+”、设置入口和窗口的最小化 / 最大化 / 关闭按钮；标题栏空白区域可拖动窗口，双击最大化或还原。

### 4.2 阅读

- F2.1 连续滚动浏览，只渲染可视区附近的页面。
- F2.2 缩放（适合宽度、适合页面、百分比）和 90 度步进的旋转。
- F2.3 高分屏下清晰显示，窗口跨屏移动后自动适配。
- F2.4 页码跳转；有大纲的 PDF 显示大纲并可跳转。
- F2.5 页面缩略图面板：显示每页缩略图，当前页高亮，点击跳转。

### 4.3 文字选择、复制、查找

- F3.1 鼠标拖选文字，支持跨行和跨页；双击选词，三击选行。
- F3.2 复制所选文字到剪贴板。中文之间不插入空格，拉丁文本按词加空格，行尾连字符合并。
- F3.3 文档内查找，高亮所有命中并可逐个跳转。
- F3.4 以上功能对 OCR 识别出的文字同样可用。
- F3.5 查找时如果有页面尚未识别，提示未识别的页数，并提供一键全部识别。
- F3.6 查找条显示命中序号和总数（如“3 / 11”），提供上一个、下一个和关闭；按 Esc 关闭。

### 4.4 标注

- F4.1 标注类型：

| 类型 | 说明 |
|---|---|
| 高亮、下划线 | 基于选中的文字 |
| 便签 | 页面上的一个图标，点开显示评论 |
| 文字批注 | 直接显示在页面上的文字框 |
| 手绘 | 自由画笔 |
| 矩形、箭头 | 基本图形 |

- F4.2 每个标注可以设置颜色，可以附带评论文字。
- F4.3 已有标注可以选中、移动、缩放、编辑评论、删除。
- F4.4 撤销和重做，每个标签页独立。
- F4.5 自动保存。关闭标签页或应用时确保落盘。
- F4.6 标注列表面板，点击跳转到标注位置。
- F4.7 标注按文件内容关联。文件改名或移动后，标注仍然存在。
- F4.8 打开的文件与上次同路径文件内容不同时，提示一次是否迁移旧标注。
- F4.9 标注作者名来自设置项，默认取 Windows 用户名。
- F4.10 选中文字后浮出操作条：高亮、下划线、便签、复制、问 AI。
- F4.11 标注列表面板按页分组，每项显示类型图标、颜色、摘要和页码；点击跳转并选中，画布上选中的标注在列表中同步高亮。
- F4.12 便签卡片显示作者、时间和评论，可编辑和删除；点击页面其它位置关闭。
- F4.13 工具栏提供颜色与线宽选择；每个绘制工具记住上次使用的颜色和线宽。

### 4.5 OCR

- F5.1 自动逐页判断是否需要 OCR：
  - 有正常原生文字的页面不识别。
  - 没有原生文字的页面做识别。
  - 只有少量原生文字且含大幅图像的页面（如带数字页眉的扫描页），两种文字合并使用。
- F5.2 用户可以对单页手动触发重新识别，或改用原生文字。
- F5.3 优先识别当前可见页面；需要全文时在后台识别全部页面，并显示进度。
- F5.4 识别结果缓存到本地，再次打开同一文档时直接使用。
- F5.5 识别过程可以取消，不阻塞界面。
- F5.6 识别进度同时显示在页面（页底“正在识别文字…”）和状态栏（“文字识别中 12 / 36 页”、进度条和取消按钮）。

### 4.6 LLM 辅助

- F6.1 设置页配置 LLM 提供方：接口地址、API Key、模型。支持 OpenAI 兼容接口，以及 pi 支持的其他提供方。
- F6.2 每个文档有自己的对话，一个文档可以有多个对话。对话保存到本地，重启后可继续。
- F6.3 回答以流式方式显示，可以中途停止。
- F6.4 LLM 可以按需读取文档：获取文档信息、读取指定页的文字、在文档内搜索、查看页面或区域的图像。
- F6.5 框选提问：在页面上框选一块区域，把该区域的图像和其中的文字一起发给 LLM。模型不支持图像输入时只发文字。
- F6.6 回答中引用原文时，引用可以点击，跳到对应页并高亮原文。
- F6.7 LLM 可以代用户创建高亮或便签。这类标注可以撤销，并与产生它的对话消息互相链接。
- F6.8 LLM 只能访问当前文档，没有访问文件系统或网络的工具。
- F6.9 请求出错（鉴权失败、限流、超时）时在对话面板显示错误原因，并允许重试。
- F6.10 对话面板顶部显示当前对话标题（可下拉切换、可重命名）、新建对话按钮和历史对话入口。
- F6.11 工具调用以简洁记录行显示在回答上方（如“已搜索文档：…”“已读取第 12–15 页”）；进行中的任务显示进度。
- F6.12 回答下方提供复制和重新生成。
- F6.13 每个对话可以选择模型，模型来自设置中已配置的提供方。
- F6.14 提供方设置包含“支持图像输入”开关；关闭时框选提问只发送文字。
- F6.15 选中文字后可以“问 AI”，把选中文字作为引用加入输入框，不直接发送。

### 4.7 设置

设置以模态对话框呈现，左侧导航为：模型提供方、标注、文字识别、关于。

- F7.1 LLM 提供方管理。
- F7.2 标注作者名、默认颜色和默认不透明度。
- F7.3 OCR 模型档位（Tiny、Small、Medium）和是否启用 GPU。
- F7.4 提供方列表支持添加、删除和设为默认；每项显示名称、接口地址和密钥状态（已配置 / 未配置）。
- F7.5 提供方表单提供“测试连接”，显示成功或失败原因，测试不保存。
- F7.6 “关于”页显示版本、运行环境和开源许可，并提供打开日志目录的入口。

### 4.8 界面布局与交互

主窗口是无边框窗口，分为四段：标题栏（含标签页）、工具栏、主体、状态栏。主体从左到右为：左侧图标栏、可展开的侧面板、文档区、可拖动的分隔条、右侧对话面板。原型图片 image1.png 至 image5.png 为原工作区的历史参考，按源码仓库要求排除；仓库内可复现的界面见 [原型说明](prototype-guide.md) 与显式 demo 页面。

- F8.1 对话面板默认约占窗口宽度的 35%，可拖动分隔条调整，双击分隔条恢复默认；有最小和最大宽度，窗口变窄时优先收窄对话面板。面板可以收起为右侧窄条，点击恢复。
- F8.2 左侧图标栏自上而下为：选择工具、页面缩略图、目录大纲、标注列表。三个面板互斥展开，再次点击同一图标收起，记住上次展开的面板。
- F8.3 工具栏分为四组：绘制工具（选择、高亮、下划线、便签、文字批注、画笔、矩形、箭头、框选提问、橡皮擦）、颜色与线宽、撤销和重做、缩放与查找（缩小、缩放比例、放大、适合宽度、旋转、查找）。
- F8.4 状态栏分三段：左侧页码（当前页 / 总页数，可点击跳转）、中间缩放控件、右侧文档状态。右侧状态按优先级显示：文字识别进度优先于自动保存提示，自动保存提示优先于文字来源。
- F8.5 空态：没有文档时显示打开文件和最近打开的入口；对话没有消息时显示输入提示。
- F8.6 视觉规范：浅色主题；主色为蓝色；圆角 8px；线性图标；界面语言为简体中文；界面字号不随文档缩放变化。
- F8.7 键盘快捷键：Ctrl+O 打开、Ctrl+W 关闭标签、Ctrl+Tab 切换标签、Ctrl+F 查找、F3 / Shift+F3 下一个 / 上一个命中、Ctrl+Z / Ctrl+Y 撤销 / 重做、Ctrl+= / Ctrl+- / Ctrl+0 缩放、Ctrl+1 适合宽度、Ctrl+2 适合页面、Ctrl+Enter 发送、PageUp / PageDown 翻页、Esc 取消当前工具或关闭浮层、Delete 删除选中标注。
- F8.8 浮层不遮挡操作目标：选择文字后的浮条位于选区上方，空间不足时翻到下方；框选工具拖出选框后，右下角显示“问 AI / 取消”。颜色选择器、便签卡片、会话下拉和查找条点击外部或按 Esc 关闭。

## 5. 非功能需求

| 编号 | 要求 |
|---|---|
| N1 安全 | API Key 只保存在宿主，用 DPAPI 加密；前端 JS 无法读取 Key |
| N2 安全 | LLM 代理只转发到用户已保存的接口地址，前端不能在请求中指定其他上游 |
| N3 隐私 | OCR 完全在本机运行；文档内容只在用户使用 LLM 功能时发送给用户配置的提供方 |
| N4 数据 | 原始文档永不被修改；标注和对话写入使用原子写，保留一份备份 |
| N5 性能 | 500 页 PDF 滚动流畅，内存稳定 |
| N6 性能 | OCR 目标：A4 页 200 DPI，CPU 上端到端小于 1.5 秒（Small 模型）[待 S3 验证] |
| N7 性能 | 标签页过多时，最久未用的文档自动释放内存，激活时重新加载 |
| N8 开发 | 前端可以脱离宿主，在浏览器中用 `pnpm dev` 独立运行和调试 |
| N9 部署 | 自包含发布，在干净的 Windows 机器上解压即可运行；检测 WebView2 运行时是否存在 |
| N10 兼容 | 没有可用 GPU 时 OCR 自动回退到 CPU |
| N11 界面 | 主窗口默认 1440×900，最小 1100×700；1366×768 屏幕上完整可用 |
| N12 界面 | 界面缩放跟随系统 DPI（100%–200%），布局不重叠、不截断 |
| N13 性能 | 缩略图按需渲染，500 页文档打开缩略图面板不阻塞滚动 |

## 6. 已知限制（v1 接受）

1. **阅读顺序**：不做分栏和表格检测。多栏文档中，选择和复制的文字顺序可能出错。
2. **OCR 语种**：SimdPaddleOCR 目前只有中文模型包。纯英文或其他语种扫描件的识别质量未验证。
3. **无障碍**：页面内容画在 Canvas 上，没有 DOM 文本层，读屏软件无法读取文档内容。
4. **超高缩放**：单页画布有像素上限，超过后会降低分辨率，放得很大时会变模糊。
5. **内容变更**：文档被其他工具修改后哈希会变，旧标注需要通过迁移提示才能继续使用，位置可能对不上。
6. **标注互通**：v1 的标注其他 PDF 阅读器看不到。
7. **窗口贴靠**：自定义标题栏下，Windows 11 贴靠布局的悬停浮出在 v1 不可用，需要宿主实现非客户区命中测试 [S0 确认 v1 不实现]。
8. **主题**：v1 只提供浅色主题，深色主题后续版本提供。

## 7. 里程碑与验收

先做四个风险验证（Spike），再进入功能里程碑。S0 和 S1 通过后开始 M1；S2 必须在 M2 之前出结论；S3 必须在 M4 之前出结论。

### 7.1 Spike

| 编号 | 验证的问题 | 通过标准 | 不通过时 |
|---|---|---|---|
| S0 | WPF + WebView2 + Vite 开发循环和桥是否顺畅 | `pnpm dev` 纯浏览器可跑；宿主内热更新正常；`/_host/ping` 往返成功 | 必须通过 |
| S1 | pi 能否在 WebView 内运行，并经宿主代理流式输出 | 流式内容逐块到达；中止后 1 秒内上游连接关闭；DevTools 中看不到 Key | 改用本机 loopback 监听；再不行用 web message 隧道；pi 不可用则自写 SSE 适配 |
| S2 | 从 PDF.js 片段级盒子推导的逐字位置是否够准 | 5 份样本中，字符盒偏差小于 0.15 字宽的比例不低于 98% | 宿主增加 PdfPig 文字几何服务 |
| S3 | OCR 往返的耗时和坐标精度 | A4 页 200 DPI 端到端小于 1.5 秒（CPU，Small 模型）；坐标叠加回页面贴合；英文扫描样本的识别质量单独记录 | 降低 DPI、改用 Tiny 模型，或改由宿主光栅化 |

S2 的 5 份样本：中文横排、中英混排、两端对齐英文、页面旋转 90 度、CropBox 有偏移。

### 7.2 功能里程碑

| 阶段 | 内容 | 验收 |
|---|---|---|
| M1 壳与阅读 | 桥、浏览器 mock、主界面框架（标题栏标签、工具栏、图标栏与面板、状态栏、分隔条）、多标签页、打开 PDF 和图片、虚拟化渲染、缩放、旋转 | 打开 500 页 PDF 滚动流畅，内存稳定；125% 和 150% 缩放的显示器上清晰；`pnpm dev` 纯浏览器同样可用；主界面结构与原型 image1 一致 |
| M2 文本 | 原生文字模型、选择、复制、查找 | 样本集跨页选择后粘贴到记事本，与 Acrobat 的复制结果对比；查找命中数一致；旋转 90 度的页面选区贴合 |
| M3 标注 | 全部标注类型、选区浮条、标注列表联动、便签卡片、撤销重做、自动保存、迁移框架 | 标注后杀进程重开，全部还原；原 PDF 的 sha256 不变；文件改名或移动后标注仍在；JSON 通过 schema 校验 |
| M4 OCR | 宿主 OCR、缓存、逐页判定、进度、手动覆盖 | 扫描 PDF 可选择、复制、查找、高亮；第二次打开直接命中缓存；带数字页眉的扫描页两类文字都可选 |
| M5 对话 | 设置对话框、对话面板（会话管理、工具记录、复制 / 重新生成、模型选择）、Agent 工具、上下文策略、持久化 | 对 300 页文档提问，能看到工具调用和正确页码；中途停止立即生效；重启后对话还在；DevTools 确认 JS 侧没有 Key |
| M6 联动 | 框选提问（选框浮条、附件卡）、引用跳转、LLM 创建标注、标注与消息互链 | 框选图表提问，回答与图相关；点击引用跳到页并高亮；LLM 创建的高亮可以撤销 |
| M7 发布 | 自包含发布、崩溃日志、WebView2 运行时检测、性能回归 | 干净的 Windows 虚拟机上解压即可运行；没有 GPU 时自动回退 CPU |

## 8. 默认决定（评审时可改）

| 问题 | 当前默认 |
|---|---|
| 标注作者名 | 设置项，默认取 Windows 用户名 |
| 加密 PDF | v1 支持输入密码 |
| 同路径文件内容变化 | 打开时提示一次是否迁移旧标注 |
